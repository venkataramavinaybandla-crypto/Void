LESSON 04.1 // TRANSPORT DYNAMICS // SGR-A* RADIO UPLINK

The Three-Way Handshake

On establishing temporal synchronization over unchaperoned vacuum.

To communicate across an indifferent topology is an act of defiance. When Host A seeks contact with Host B, neither possesses shared clocks nor guaranteed arrival. The radio telemetry traversing galactic void is vulnerable to arbitrary phase slips, deep packet fragmentation, and the catastrophic re-emergence of ghost packets released minutes or epochs prior.

The fundamental dilemma is not transmission speed, but the coordination of state machines in the presence of unreliable channels. In classical IP networks, a datagram is uncommitted dust. Transmission Control Protocol (TCP) builds an immortal, reliable illusion over this unchaperoned dust. It achieves consensus not through continuous presence, but by an atomic sequence of exactly three state-asserting emissions.

KEY OBSERVATION // CONSENSUS PRINCIPLE

The handshake does not merely announce intent; it establishes symmetric state machines against delayed duplicate packets drifting through orbital buffers.

§ 02. The Initial Sequence Number (ISN) [AXIOM]

Neither side begins counting from zero. A static zero origin would invite catastrophic vulnerability: a delayed segment from a dead connection might re-enter the interface queue and be swallowed as legitimate payload by a successor session. Thus, Host A generates an Initial Sequence Number ($ISN_A$) derived from a pseudo-random progression tied to real-time monotonic clocks:

§ 04. Half-Open Horizon Leaks [ENTROPY]

When Host A sends its SYN and promptly suffers a power disruption or loss of link before receiving packet 2, Host B remains suspended in state [SYN_RECEIVED]. It commits transmission control blocks (TCBs) to memory.

In deep-space networks where round-trip times expand to tens of minutes, unacknowledged semi-connections consume buffer horizons like dead satellites orbiting in graveyard trajectories.
